# 미승인 규칙 후보

Taeguk 저장소의 [기존 규칙 목록](https://github.com/sensibile/taeguk/blob/main/docs/research/archive/규칙-목록.md) 후보 중 현행 registry에 등록되지 않은 항목은 계속 제안 상태다. archive는 원본을 보존하며 현행 규칙의 승인 목록으로 사용하지 않는다.

## GOV-005

작업·정리·재시도 한도는 목적과 비용에 맞춰 정할 후보다. 전역 횟수·시간·예산은 합의하지 않았다. 실제 반복 작업에서 실패 패턴과 비용을 관측한 뒤 제안한다.

새 개정안은 Taeguk 저장소에서 작성하며 현재 ID·버전, 문제 사례, 변경 전후 판정, 정상·실패 사례 검사, 비용·권한 영향, 전환·되돌림 조건을 기록한다. BOSS 확인 전에는 현행 기준을 유지한다. 스킬: taeguk-propose-rule-change.

## VER-005

리뷰 반복 종료·상향 기준 후보다. 2026-10-28 BOSS가 공통 기준으로 확정했고 정식 규칙 등록을 별도 개정안으로 진행하도록 결정했다. 본문 제안, 변경 전후 판정, 전환·되돌림 조건은 [리뷰 반복 종료·상향 기준 개정안](review-loop-exit.md)에 있다. BOSS 확인 전에는 현행 규칙을 유지하며, 그동안 운영 기준은 work-contract의 작업 단계 참고 문서다.

## 의도·요구사항 기록

2026-10-23 승인되어 REQ-001 1.1과 REQ-007 1.0으로 현행 규칙에 반영했다. [의도·요구사항 기록 개정안](intent-requirement-records.md)은 개정 근거로 보존한다.
