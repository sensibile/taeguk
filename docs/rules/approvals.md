# 규칙 승인 근거

## Approval-2026-10-05

근거: 이 대화에서 BOSS가 “규칙의 적용은 에이전트가 자유롭게 사용하고 규칙의 변경은 사용자 확인으로 하면 되겠다”라고 지시했다. GOV-001과 GOV-002의 기존 합의를 유지한다. 원래 기록은 [규칙 목록](../research/archive/규칙-목록.md)과 [규칙 관리](../research/archive/규칙-관리.md)에 보존한다.

## Approval-2026-10-11

근거: 직전 응답에서 공통 원칙 8개와 보관 구성을 제시한 뒤 BOSS가 “응 그럼 일단 이렇게 룰도 추가해줘. 그리고 작업 진행하면서 필수로 필요한건... 기계적으로 체크하도록 빌드업하자”라고 지시했다.

등록 범위: REQ-001, GOV-004, VER-003, VER-004, MET-001, REQ-006, REL-005, DEV-002의 Taeguk 공통 원칙. 세부 본문은 제안의 의미와 기존 문서의 조건을 보존한다. 규칙 저장 형식과 참조에 대한 로컬 검사 기반을 포함한다. 수치 기준, 운영 권한, archive의 다른 후보, 규칙 자동 변경은 포함하지 않는다.

승인 근거는 대화 기록의 로컬 요약이다. 전자서명이나 별도 권한 시스템의 증명이 아니며 검사 도구도 그 진실성을 인증하지 않는다.
