# 개발 지침 검토 안내

2026-10-05 · 여섯 권 전체 본문 검토와 적용 지침 통합 완료 · 새 규칙은 제안 상태

기술 보완용 여섯 권의 모든 본문 장과 코드·표·도식을 읽고, 적용 조건·반례·검증할 경계를 정리했다. 앞선 일부 검토를 전체 완료로 표현했던 상태는 철회했으며, 이번 범위는 [전체 읽기 기록](전체-읽기-기록.md)에 책별·장별로 명시했다.

## 읽는 순서

1. [구현 기술 심화](구현-기술-심화.md): 설계·레거시·검사·데이터·장애·에이전트의 구현 판단. 8절은 전체 읽기 보완, 9절은 자율 수정 실행 계약, 10절은 규칙 진화 제안.
2. [적용요소 정밀검토](적용요소-정밀검토.md): 적용 전제, 잘못 적용되는 반례, 필요한 증거.
3. [전체 읽기 기록](전체-읽기-기록.md): 여섯 권의 확인 범위와 장별 근거, 원문 예제의 불일치.
4. [반례 실험](experiments/README.md): 실행한 Python 네 가지와 Java 최소 재현, 결과와 한계.

## 보존한 기존 문서

[개발 사이클](개발-사이클.md), [규칙 관리](규칙-관리.md), [규칙 목록](규칙-목록.md), [서적 검토](서적-검토.md), [구현 이론 보완계획](구현-이론-보완계획.md), [구현 판단 지침](구현-판단-지침.md)은 변경하지 않았다. 이들에 있는 미독·선택 검토 표기는 당시 기록이다. 앞선 구현 기술 여섯 권의 검토 범위는 이 안내와 전체 읽기 기록을 기준으로 한다.

규칙 적용은 승인된 범위에서 에이전트가 수행하고, 규칙의 의미·합격선·허용 행동 변경은 BOSS 확인을 받는 합의를 유지한다. 이번 문서 작성은 규칙 승인이나 자동 배포 권한 부여가 아니다.

## 완료 범위와 실행 한계

완료한 것은 여섯 권 본문 검토와 적용 지침 정리다. DDIA 색인은 일부 탐색 확인이며 표지·판권과 외부 참조 원문 전체는 기술 적용 검토에 포함하지 않는다. 연습문제와 제공 해설을 읽은 것과 모든 문제를 독립적으로 풀어 실행한 것도 구분한다.

실행한 것은 자체 교육용 반례 실험과 최소 언어 재현이다. 모든 예제, 실제 제품·운영 DB·브로커·AI 평가·배포를 실행 검증하지 않았다. 구체 제품에 적용할 때는 해당 언어·DB·라이브러리 버전과 실제 실패·복구 경계를 확인해야 한다. 스킬·에이전트 구현은 이번 문서 검토 결과와 별개다.


## 추가: 검증 도구와 지표의 선택 검토

이번에 추가한 검증 서적 여섯 권은 전체 정독 대신 적용 조건·판정 근거·교차 검사·한계를 설명하는 데 필요한 구간을 선택해서 읽었다. 위의 구현 기술 여섯 권 전체 읽기 완료와 별도 범위다.

- [검증 도구 선택 지침](검증-도구-선택-지침.md): 작업 속성별 도구 후보, 교차 검사, 지표, 결과 상태, 검증계획 양식.
- [검증 서적 선택 검토](검증-서적-선택검토.md): 책별 확인 범위, 제외한 부분, 추출 근거와 적용 주의.

새 문서는 승인 전 제안이다. 검증 도구 설치·실행이나 제품 배포 검증을 완료한 기록이 아니다.
